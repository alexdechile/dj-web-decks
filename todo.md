# Hoja de Ruta del Proyecto DJ Web Decks

A continuación se listan las posibles futuras funcionalidades y mejoras para la aplicación.

## Funcionalidades Principales

- [ ] **Mezclador Avanzado:**
  - [ ] Ecualizador de 3 bandas (Bajos, Medios, Agudos) por canal.
  - [ ] Filtros (Pasa-altos / Pasa-bajos) por canal.
  - [ ] Control de ganancia/volumen individual por canal.

- [ ] **Análisis de Pista:**
  - [ ] Detección automática de BPM (Beats Per Minute) al cargar una canción.
  - [ ] Visualización de la forma de onda (waveform) completa de la pista.
  - [ ] Detección de la tonalidad (key) de la canción para mezcla armónica.

- [ ] **Librería y Playlists:**
  - [ ] Sistema para guardar canciones favoritas.
  - [ ] Creación y gestión de playlists personalizadas.
  - [ ] Integración con una base de datos local (IndexedDB) para persistir la librería.

- [ ] **Controles de Deck Avanzados:**
  - [ ] Hot Cues: Marcar y saltar a puntos específicos de la canción.
  - [ ] Loops: Crear y controlar bucles (loops) de una duración determinada.
  - [ ] Botón "Sync" para igualar los BPM de ambos decks automáticamente.

- [ ] **Mejoras de Interfaz y Experiencia:**
  - [ ] Mejorar el diseño del mezclador para dar cabida a los nuevos controles.
  - [ ] Añadir más feedback visual a los controles (botones que se iluminan, etc.).
  - [ ] Implementar "drag and drop" para cargar canciones desde una lista a los decks.
